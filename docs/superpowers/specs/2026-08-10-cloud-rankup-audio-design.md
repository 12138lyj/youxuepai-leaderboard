# 优学湃云端自定义晋级音效设计

## 目标

在现有三种内置晋级音效之外，允许管理员上传自己的音频文件，或填写可直接播放的 HTTPS 音频网址。音效配置保存到现有 Supabase 云端排行榜状态，所有设备读取同一选择；音频不可用时自动回退到内置“王者号角”。

## 已确认范围

- 保留“王者号角”“水晶解锁”“星耀冲刺”三种内置音效。
- 音效来源支持“内置音效”“上传文件”“音频网址”。
- 音效是全站统一设置，不随班级切换而变化。
- 只有已登录管理员可以修改，普通访客只使用同步后的设置。
- 支持 MP3、M4A、WAV、OGG，上传文件最大 10MB。
- 上传完整音乐后，用滑块选择固定 5.2 秒的片段并可反复试听。
- 自定义音频必须至少 5.2 秒；更短的音频不能保存为晋级音效。
- 晋级动画播放所选 5.2 秒；动画结束、关闭或跳过时停止音频。
- 自定义音频加载或播放失败时自动回退到“王者号角”。

## 方案选择

曾考虑三种方案：只保存在本机、只保存外部网址，以及上传文件和网址都保存到云端。采用第三种，因为它同时满足跨设备同步和使用灵活性，并保留内置音效作为网络异常时的可靠备用。

片段截取采用无损的“保存完整音乐并同步播放起点”方案，不在浏览器中重新编码，也不增加服务器转码服务。与浏览器生成裁剪文件或云端转码相比，该方案速度更快、格式兼容性更稳定，且不会降低音质；所有设备根据同一 `clipStart` 只播放选中的 5.2 秒。

## 数据结构

在现有顶层 `appState` 中增加 `rankupSound`：

```json
{
  "enabled": true,
  "source": "builtin",
  "style": "horn",
  "url": "",
  "name": "王者号角",
  "storagePath": "",
  "clipStart": 0,
  "clipDuration": 5.2
}
```

- `enabled`：是否播放晋级音效。
- `source`：`builtin`、`upload` 或 `url`。
- `style`：内置备用音效，始终限制为三个已知值之一。
- `url`：上传文件的公开地址或管理员填写的 HTTPS 直链。
- `name`：界面显示名称。
- `storagePath`：仅上传文件使用，供替换时清理旧文件。
- `clipStart`：所选片段的开始秒数，精确到 0.1 秒。
- `clipDuration`：固定为 5.2 秒，不接受其他值。

`State.normalizeAppState` 负责填充默认值和剔除无效字段。旧云端数据没有该字段时自动使用“王者号角”，无需迁移学员或积分数据。

## 云端存储

新增 Supabase Storage 公共桶 `rankup-audio`：

- 公开读取，确保未登录访客和所有设备都能播放。
- 只允许已登录且拥有排行榜主记录的管理员上传、替换和删除。
- 桶级限制为 10MB 和四类音频 MIME 类型。
- 文件路径使用 `main/<timestamp>-<safe-name>`，避免浏览器缓存旧音频。

网页保存完整原始音频，不在浏览器内转码或生成新文件，避免速度慢、格式兼容问题和音质损失。上传完成后，网页先取得公开 URL 并读取音频时长；管理员选定片段后，再把 URL、文件信息和 `clipStart` 写入现有 `leaderboard_state.payload`。替换上传音频时，在新设置成功进入保存队列后尝试删除旧对象；清理失败不影响新音频使用。

## 页面交互

编辑抽屉中的“晋级音效”区域包含：

- 来源切换：内置音效、上传文件、音频网址。
- 内置来源显示原有三种音效选择。
- 上传来源显示文件选择按钮、当前文件名和“替换音频”。
- 网址来源显示 HTTPS 直链输入框和“使用此网址”。
- 上传文件或网址加载完成后显示片段选择器：开始位置滑块、开始时间、结束时间和固定的“5.2 秒”标签。
- 滑块范围为 `0` 到 `音频总时长 - 5.2`，步长为 0.1 秒；例如显示 `00:12.4 - 00:17.6`。
- “试听片段”只播放当前滑块选中的 5.2 秒，可重复试听；“保存这个片段”才会把截取位置同步到云端。
- 所有来源共用“试听”和“播放晋级音效”开关。
- 自定义音频无效时显示提示，并自动试听或播放“王者号角”。
- “恢复内置音效”将来源和选择恢复为默认的“王者号角”。

上传、读取时长和保存片段期间禁用对应按钮，防止重复提交。音频网址只接受 HTTPS 且路径以 `.mp3`、`.m4a`、`.wav` 或 `.ogg` 结尾；可带查询参数。音频不足 5.2 秒或无法读取时长时不允许保存，并保持原有云端音效不变。

## 播放流程

1. 积分跨过段位门槛时启动 5.2 秒晋级动画。
2. 若音效关闭，则不播放。
3. `builtin` 使用现有 Web Audio 合成音效。
4. `upload` 或 `url` 使用浏览器音频元素加载同步后的 URL，并从 `clipStart` 开始播放。
5. 到达 `clipStart + 5.2`、动画结束、关闭、跳过或下一次动画开始时，停止并释放当前音频。
6. 自定义音频的 `play()` 被拒绝、触发错误或 URL 无效时，只回退一次“王者号角”，避免重复声音。

## 错误处理

- 文件类型或大小不合规：上传前阻止并显示明确原因。
- 音频短于 5.2 秒或无法取得可靠时长：不显示可保存状态，并保留原音效。
- Storage 上传失败：保留当前音效设置，不写入失效 URL。
- 云端状态保存失败：沿用现有待同步机制，页面保留本地修改并在网络恢复后重试。
- 外部 URL 失效或跨域播放失败：回退“王者号角”，不清空管理员填写内容。
- 旧上传文件删除失败：静默保留旧对象，不影响当前设置。
- 普通访客无法通过页面或 Storage API 修改音频。

## 测试与验收

### 自动测试

- 状态规范化：旧数据默认值、三种来源、非法来源、非法 URL、截取起点和固定片段时长。
- 文件校验：四种格式、10MB 边界、超限、错误类型和不足 5.2 秒。
- 片段选择：滑块上下限、0.1 秒步长、时间格式和保存前后状态。
- 播放：从截取起点开始、5.2 秒停止、手动停止、重复试听和失败后单次回退。
- 云端模块：上传路径、公开 URL、替换和删除失败不阻塞。
- UI：三种来源切换、上传、网址保存、试听、恢复默认和管理员门禁。
- 回归：现有积分、段位、动画、班级切换和 65 项测试继续通过。

### 线上验收

- 管理员在一台设备上传音乐并保存选中的 5.2 秒后，另一台设备刷新或收到实时更新后显示相同时间范围并可试听。
- 管理员填写有效 HTTPS 音频直链并保存片段后，所有设备在晋级时播放同一个 5.2 秒片段。
- 关闭音效后所有设备同步静音。
- 使用失效链接触发晋级时仍能听到“王者号角”。
- 上传超过 10MB 或非音频文件时不改变现有设置。
- GitHub 仓库和网页源码中不出现管理员密码、数据库密码或私密密钥。

## 发布

1. 在 Supabase 执行 Storage 桶和权限迁移。
2. 按测试先行方式修改状态、音频、云端和界面模块。
3. 完整运行自动测试和本地桌面/移动端浏览器验收。
4. 推送 GitHub Pages 并等待构建成功。
5. 在正式网址验证云端读取、管理员上传、跨设备同步和失败回退，随后删除测试音频。
